# 更新日志

所有面向用户的可见变更记录于此，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [0.2.2] - 2026-09-12

### 修复

- macOS 点击菜单栏托盘图标无法唤回主窗口的问题

## [0.2.1] - 2026-09-11

### 新增

- 系统通知：AI 文稿生成、视频生成、草稿批量生成完成后发送系统通知（切到其他窗口时提示，正在使用时不打扰）
- 设置 → 通用 → 系统通知：新增「测试」按钮，可直接验证系统通知权限与投递

### 修复

- 顶部标题栏内容区双击无法最大化 / 还原窗口的问题

## [0.2.0] - 2026-09-11

### 新增

- 多项自用功能以及在线更新

## [0.1.0] - 2026-08-31

### 新增

- 「暗色指挥台」主题：默认暗色，亮色同步重调
- 侧边栏可收起为图标 rail，macOS 红绿灯区域避让
- 字号三档设置（小 / 正常 / 大），控件与文字等比缩放
- 主题色新增「国家电网绿」
- 设置页新增「更新日志」与「关于」页（Markdown 驱动）

### 修复

- macOS 标题被红绿灯遮挡的问题
- 工具内容区居中导致空间浪费的问题
- Toast 通知样式缺失导致位置错误的问题
- 按钮等控件文字过大、与输入框不等高的问题
