# 更新日志

所有面向用户的可见变更记录于此，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [0.3.0] - 2026-09-13

### 新增

- 「网络工具」插件，含「接口测试」与「请求拦截」两个工具
  - **接口测试**：模拟 GET/POST 等请求，支持 Query、Headers、Cookie 与请求体（Raw、表单、multipart 文件、二进制）以及认证（Basic、Bearer、API Key）
  - **接口测试**：环境变量 `{{变量}}` 替换、cURL 与自有 JSON 导入导出、任意层级集合与文件夹、历史记录与草稿、请求取消
  - **接口测试**：响应查看支持 JSON / XML / HTML 自动美化，展示响应头与 Set-Cookie
  - **请求拦截**：本地 MITM 代理，捕获并查看 HTTP(S) 流量，可按 Host / 方法 / 状态 / 类型过滤
  - **请求拦截**：编辑捕获到的请求并重放，WebSocket 帧只读查看，根证书导出与安装指引
  - **请求拦截**：一键设置系统代理（macOS / Windows），停止代理时自动还原

### 变更

- 侧边栏插件顺序调整为：常用工具 · 网络工具 · 内容创作 · 投标工具
- 「投标报价」更名为「投标工具」；「图文视频工具」更名为「视频工具」
